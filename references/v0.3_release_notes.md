# v0.3.0 发布说明

发布日期：2026-03-03

## 版本摘要

- 版本号：`0.3.0`
- Git 标签：`v0.3.0`
- 发布范围：`schema diff/plan`、`schema migration execute`、`template render`、`repair runner`、`snapshot/rollback`

## 关键新增能力

- 新增 `schema-diff` / `schema-migration-plan`，支持结构化 diff 与迁移计划输出。
- 新增 `apply-schema-migration`，支持 `--dry-run` 与 `--execute --yes` 双阶段执行。
- 新增 `render-template`，支持模板变量注入与渲染。
- 新增 `repair-runner`，统一修复器框架与 `audit_log` 输出。
- 新增 `snapshot-collab` / `rollback-collab`，支持快照采集与回滚流程。
- `schema_lib.build_schema_diff` 支持基于 `field_id` 的 rename 识别（`confidence=1.0`）。

## 验证结果（真实联调）

- 已完成 v0.3 M1~M4 全链路联调（含 dry-run 串联）。
- 已完成 database 对象快照与回滚实测，回滚后 `after_diff_summary` 为 0，字段名恢复成功。
- 回归记录见：`references/v0.3_m4_regression.md`。

## 兼容性与风险提示

- `rollback-collab` 默认 `auto` 策略：database 优先 `schema-database`，其他对象走 `state-update`。
- database 回滚建议优先使用 snapshot 中的 `database_schema_fields`，避免 CRDT 合并导致状态不一致。
- 执行型命令默认推荐先 `--dry-run`，生产环境再使用 `--execute --yes`。
