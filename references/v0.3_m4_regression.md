- 先创建临时字段并改名制造偏差：

### dry-run
命令：
```bash
python skills/appflowy-api/scripts/appflowy_skill.py rollback-collab \
  --config skills/appflowy-api/references/config.example.json \
  --email <email> --password <password> \
  --snapshot-file .tmp/v03_m4_db_snapshot_v2.json
```

结果摘要：
- `strategy=schema-database`（auto 选择）
- `before_diff_summary.rename_candidate_count=1`

### execute
命令：
```bash
python skills/appflowy-api/scripts/appflowy_skill.py rollback-collab \
  --config skills/appflowy-api/references/config.example.json \
  --email <email> --password <password> \
  --snapshot-file .tmp/v03_m4_db_snapshot_v2.json \
```

结果摘要：
- `strategy=schema-database`

- `operation_results` 中 `rename_field` 执行成功
